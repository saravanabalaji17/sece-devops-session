

## **1. GitLab Shared Runner – Without Ubuntu image**

You want to execute Linux shell commands without specifying an image.

`.gitlab-ci.yml`

```

stages:
  - test

ubuntu_shell_job:
  stage: test
  script:
    - echo "GitLab Shell Runner Example"
    - echo "Current user"
    - whoami
    - echo "Hostname"
    - hostname
    - echo "Operating System"
    - cat /etc/os-release
    - echo "Disk Usage"
    - df -h
    - echo "Memory"
    - free -h
    - uptime
    - echo "Hello GitLab Shared Runner"
    - whoami
    - hostname
    - pwd
    - uname -a
    - df -h
    - free -h
    - hostname -I
    - cat /etc/os-release

```

**Expected output (illustrative):**

```
GitLab Shell Runner Example
Current user
gitlab-runner

Hostname
ubuntu-runner01

Operating System
Ubuntu 24.04 LTS

Disk Usage
/dev/sda2  50G  15G  35G  30%

Memory
Mem:  8Gi

up 10 days
```

This works when the assigned runner uses Shell executor and has Ubuntu installed. It is not a GitLab.com hosted Shared Runner configuration you can request.

## **2. GitLab Shared Runner – With Ubuntu image**

For GitLab.com hosted runners, use this example.

`.gitlab-ci.yml`

```

stages:
  - test

ubuntu_docker_job:
  stage: test

  image: ubuntu:24.04

  script:
    - echo "GitLab Shared Runner with Ubuntu Image"
    - echo "Current user"
    - whoami
    - echo "Hostname"
    - hostname
    - echo "Operating System"
    - cat /etc/os-release
    - echo "Disk Usage"
    - df -h
    - echo "Memory"
    - cat /proc/meminfo | head
    - echo "CPU"
    - nproc
    - echo "Hello GitLab Shared Runner"
    - whoami
    - hostname
    - pwd
    - uname -a
    - df -h
    - free -h
    - hostname -I
    - cat /etc/os-release

```

**Expected output (illustrative):**

```
GitLab Shared Runner with Ubuntu Image

Current user
root

Hostname
runner-xxxxxxxx-project-123

Operating System
Ubuntu 24.04 LTS

Disk Usage
Filesystem  Size  Used  Avail
overlay      50G   10G    40G

Memory
MemTotal: ...

CPU
2
```

Here, Ubuntu 24.04 runs inside a Docker container, not directly on the runner host.

## **4. Final comparison**

| Feature          | Shell executor        | Ubuntu image                   |
| ---------------- | --------------------- | ------------------------------ |
| Runner           | Self-managed          | GitLab hosted                  |
| `image:`         | Not required          | Required or default configured |
| Environment      | Ubuntu host           | Ubuntu container               |
| `whoami`         | Usually gitlab-runner | Usually root                   |
| `hostname`       | Hostname              | Container hostname             |
| Install packages | Host installation     | Container installation         |
| Isolation        | Limited               | Container isolation            |

**My recommendation:** Practice the second example with GitLab.com. For your Linux administration and Ansible automation practice, create a self-managed Ubuntu Shell Runner as a separate exercise.
