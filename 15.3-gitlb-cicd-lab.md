# **Lab: Build and Push Docker Image Using GitLab CI/CD**


## **1. Lab objective**

In this lab, we will:

1. Create a Docker Hub repository.
2. Create a GitLab repository.
3. Add Docker Hub username and password as GitLab CI/CD variables.
4. Clone the GitLab repository.
5. Create a Dockerfile.
6. Create a `.gitlab-ci.yml` file.
7. Build a Docker image using GitLab CI/CD.
8. Push the image to Docker Hub.
9. Validate the image.

## **2. Lab architecture**

**GitLab Repository**

Dockerfile + index.html + .gitlab-ci.yml

**GitLab CI/CD Pipeline**

GitLab Runner + Docker-in-Docker

**Build Docker Image**

Authenticate and push image

**Docker Hub Repository**

Image successfully published

## **3. Prerequisites**

- GitLab account: [GitLab](https://gitlab.com?utm_source=chatgpt.com)
- Docker Hub account: [Docker Hub](https://hub.docker.com?utm_source=chatgpt.com)
- Git installed on your local machine.

## **4. Create Docker Hub repository**

1. Login to Docker Hub.
2. Go to Repositories.
3. Click Create repository.
4. Repository name: `gitlab-docker-demo`
5. Select Public.
6. Click Create.

Example:

```
Docker Hub username: balaji123

Repository: gitlab-docker-demo

Image name:
balaji123/gitlab-docker-demo
```

Generate a Docker Hub access token with Read & Write permissions.

Use this token instead of your account password.

## **5. Create GitLab repository**

1. Login to GitLab.
2. Click New project.
3. Select Blank project.
4. Project name: `gitlab-docker-demo`
5. Visibility: Private.
6. Click Create project.

## **6. Add GitLab CI/CD variables**

Navigate to:

`GitLab Project → Settings → CI/CD → Variables`

Add the following variables:

| Variable key      | Value                        |
| ----------------- | ---------------------------- |
| `DOCKER_USERNAME` | Your Docker Hub username     |
| `DOCKER_PASSWORD` | Your Docker Hub access token |

Recommended settings:

- Visibility: Masked
- Protect variable: Disabled for this beginner lab if using an unprotected branch.

## **10. Create .gitlab-ci.yml**

Create a file named `.gitlab-ci.yml`.

This example has only one job: `build-image-job`.

The job will:

- Start Docker CLI and Docker-in-Docker service.
- Build the Docker image.
- Login to Docker Hub.
- Push the Docker image.

```

stages:
  - build

build-image-job:
  stage: build

  image: docker:27.5.1-cli

  services:
    - name: docker:27.5.1-dind
      alias: docker

  variables:
    DOCKER_HOST: tcp://docker:2376
    DOCKER_TLS_CERTDIR: "/certs"
    DOCKER_TLS_VERIFY: "1"
    DOCKER_CERT_PATH: "$DOCKER_TLS_CERTDIR/client"

  script:
    - docker info

    - docker build -t "$DOCKER_USERNAME/gitlab-docker-demo:latest" .

    - echo "$DOCKER_PASSWORD" | docker login -u "$DOCKER_USERNAME" --password-stdin

    - docker push "$DOCKER_USERNAME/gitlab-docker-demo:latest"

    - docker logout

```

**Understand the important commands:**

| Command         | Purpose                    |
| --------------- | -------------------------- |
| `docker info`   | Checks Docker connection   |
| `docker build`  | Builds Docker image        |
| `docker login`  | Login to Docker Hub        |
| `docker push`   | Pushes image to Docker Hub |
| `docker logout` | Logs out from Docker Hub   |

Note: Docker-in-Docker requires a GitLab Runner configured with privileged execution. The runner must support this configuration.

## **14. Validate image manually**

On your local machine, run:

```
docker pull <DOCKER_USERNAME>/gitlab-docker-demo:latest
```

Check image:

```
docker images
```

Run container:

```
docker run -d \
  --name my-container \
  -p 8080:80 \
  <DOCKER_USERNAME>/gitlab-docker-demo:latest
```

Check container:

```
docker ps
```

Open browser:

```
http://localhost:8080
```

Expected output:

Success
