# ** Lab: GitLab CI/CD with Docker and Shell Runner**



## **Lab objective**

Create a GitLab repository, configure Docker Hub credentials, install GitLab Runner with Shell executor, and automatically build and deploy a website using Docker.

## **Step 1: Create GitLab repository**

1. Login to [GitLab](https://gitlab.com?utm_source=chatgpt.com).
2. Click **New project**.
3. Select **Create blank project**.
4. Enter project name:

```
christmas-piano
```

5. Select Private.
6. Click Create project.

## **Step 2: Create Docker Hub credentials**

1. Login to [Docker Hub](https://hub.docker.com?utm_source=chatgpt.com).
2. Go to Account Settings → Personal access tokens.
3. Create a token with Read & Write permission.
4. Copy the token.

## **Step 3: Add GitLab variables**

Open your GitLab project.

Go to:

**Settings → CI/CD → Variables → Add variable**

Create two variables:

| Key             | Value                    |
| --------------- | ------------------------ |
| DOCKER_USERNAME | Your Docker Hub username |
| DOCKER_PASSWORD | Docker Hub access token  |

Enable Masked and Hidden for the password variable if available.

## **Step 4: Install Docker on Ubuntu VM**

Login to your Ubuntu 24.04 VM.

```
sudo apt update
sudo apt install docker.io -y
```

Start Docker:

```
sudo systemctl enable --now docker
```

Validate:

```
sudo docker run hello-world
```

## **Step 5: Install GitLab Runner**

Install required packages:

```
sudo apt install curl -y
```

Add GitLab Runner repository:

```
curl -L https://packages.gitlab.com/install/repositories/runner/gitlab-runner/script.deb.sh | sudo bash
```

Install:

```
sudo apt install gitlab-runner -y
```

Validate:

```
gitlab-runner --version
sudo systemctl status gitlab-runner
```

## **Step 6: Create and register Runner**

In GitLab:

1. Open your project.
2. Go to Settings → CI/CD → Runners.
3. Click Create project runner.
4. Add tag:

```
shell-runner
```

5\. Create runner and copy its authentication token.

On Ubuntu:

```
sudo gitlab-runner register
```

Enter:

```
URL: https://gitlab.com
Token: <YOUR_RUNNER_TOKEN>
Description: ubuntu-shell-runner
Tags: shell-runner
Executor: shell
```

Validate:

```
sudo gitlab-runner list
```

Check GitLab UI. Runner should show Online.

## **Step 7: Give Docker permission to Runner**

```
sudo usermod -aG docker gitlab-runner
```

Restart Runner:

```
sudo systemctl restart gitlab-runner
```

Validate:

```
sudo -u gitlab-runner docker ps
```

## **Step 8: Clone GitLab repository**

```
git clone https://gitlab.com/<username>/christmas-piano.git
```

Go inside:

```
cd christmas-piano
```

## **Step 9: Create Dockerfile**

```
vi Dockerfile
```

Paste:

```

FROM ubuntu:24.04

LABEL maintainer="admin@localhost"

RUN apt update && \
    apt install -y nginx wget curl zip unzip && \
    rm -rf /var/lib/apt/lists/*

RUN wget -O /tmp/web.zip https://templatemo.com/download/templatemo_604_christmas_piano && \
    unzip -q /tmp/web.zip -d /tmp/web && \
    rm -rf /var/www/html/* && \
    cp -r /tmp/web/*/* /var/www/html/ && \
    rm -rf /tmp/web /tmp/web.zip

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]

```

Save and exit.

## **Step 10: Create .gitlab-ci.yml**

```
vi .gitlab-ci.yml
```

Paste:

```

stages:
  - build
  - deploy

build-image-job:
  stage: build

  tags:
    - shell-runner

  before_script:
    - echo "$DOCKER_PASSWORD" | docker login -u "$DOCKER_USERNAME" --password-stdin

  script:
    - hostname
    - whoami
    - docker ps -a

    - docker build -t $DOCKER_USERNAME/christmas-piano:$CI_PIPELINE_ID .
    - docker tag $DOCKER_USERNAME/christmas-piano:$CI_PIPELINE_ID $DOCKER_USERNAME/christmas-piano:latest

    - docker push $DOCKER_USERNAME/christmas-piano:$CI_PIPELINE_ID
    - docker push $DOCKER_USERNAME/christmas-piano:latest

deploy-job:
  stage: deploy

  tags:
    - shell-runner

  before_script:
    - echo "$DOCKER_PASSWORD" | docker login -u "$DOCKER_USERNAME" --password-stdin

  script:
    - docker rm -f mydevops-container || true

    - docker pull $DOCKER_USERNAME/christmas-piano:$CI_PIPELINE_ID

    - docker run -d -p 8080:80 --name mydevops-container --restart unless-stopped $DOCKER_USERNAME/christmas-piano:$CI_PIPELINE_ID

    - docker ps -a
    - docker logs --tail 20 mydevops-container
    - curl -f http://localhost:8080/

```

## **Step 11: Push files to GitLab**

```
git add Dockerfile .gitlab-ci.yml

git commit -m "Initial Docker CI CD pipeline"

git push origin main
```

## **Step 12: Validate pipeline**

Open GitLab:

**Build → Pipelines**

Expected:

**GitLab Pipeline**

Expected

1\. build-image-job

Passed

2\. deploy-job

Passed

## **Step 13: Validate Docker container**

On Ubuntu VM:

```
docker ps -a
```

Check logs:

```
docker logs mydevops-container
```

Check application:

```
curl http://localhost:8080
```

Open browser:

```
http://<VM-PUBLIC-IP>:8080
```

Allow inbound TCP port 8080 in your cloud VM firewall/security rules.
